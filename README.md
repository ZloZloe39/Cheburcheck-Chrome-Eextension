# Cheburcheck для Chrome

Простое расширение для Google Chrome: проверяет сайты на блокировку — по спискам Роскомнадзора и заблокированным CDN-провайдерам — через сервис **[cheburcheck.ru](https://cheburcheck.ru/)**.

- Сайт сервиса: <https://cheburcheck.ru/>
- Репозиторий: <https://github.com/ZloZloe39/Cheburcheck-Chrome-Eextension>

## Возможности

- **Правый клик по ссылке** (или по странице) → «Проверить блокировку» — без перехода на другой сайт.
- **Индикатор на иконке расширения**: красный ✕ — заблокирован, зелёный ✓ — не заблокирован.
- **Окошко у иконки** со списком последних 10 проверок: статус, причины, время. Поддерживает светлую и тёмную тему (следует за темой Chrome/Windows).
- **Страница отчёта**: клик по результату открывает вкладку с полным результатом проверки, кнопкой «Открыть сайт» и предпросмотром сайта.
- Системные уведомления о результате (если ОС их разрешает).

## Как пользоваться

1. Наведите курсор на любую ссылку (или откройте нужный сайт).
2. Нажмите **правую кнопку мыши** → **«Проверить блокировку»**.
3. На иконке расширения в тулбаре появится значок: ✓ (не заблокирован) или ✕ (заблокирован).
4. Кликните по иконке — в окошке будет результат с причинами; клик по домену откроет полную страницу отчёта.

Пункт меню для страницы (не по ссылке) доступен при правом клике по пустому месту на странице — проверяется домен открытой вкладки.

## Установка

### Из релиза (рекомендуется)

1. Скачайте архив с последней версией во вкладке [Releases](https://github.com/ZloZloe39/Cheburcheck-Chrome-Eextension/releases).
2. Распакуйте архив в любую папку.
3. Откройте `chrome://extensions`.
4. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
5. Нажмите **«Загрузить нераспакованное расширение»** и выберите распакованную папку.

### Из исходников

```bash
git clone https://github.com/ZloZloe39/Cheburcheck-Chrome-Eextension.git
```

Дальше — шаги 3–5 из инструкции выше, выбрав папку `Cheburcheck-Chrome-Eextension`.

## Как это работает

Расширение отправляет один GET-запрос к публичному API сервиса [cheburcheck.ru](https://cheburcheck.ru/):

```
GET https://cheburcheck.ru/api/v1/check?target=<домен-или-IP>
```

и показывает ответ в окошке расширения, на странице отчёта и (если разрешено) системным уведомлением. Ключевые поля ответа: `blocked`, `rkn_domain` (домен из списка РКН), `cdn_providers` (заблокированные CDN и их подсети), `whitelist`.

Ограничение сервиса: **30 запросов в минуту** с одного IP — при превышении расширение покажет ошибку, просто подождите немного.

## Состав проекта

```
├── manifest.json   # манифест v3: contextMenus, notifications, storage; хост cheburcheck.ru
├── background.js   # сервис-воркер: контекстное меню, запрос к API, история в storage, бейдж иконки
├── popup.html/js   # окошко у иконки: последние проверки (светлая/тёмная тема)
├── results.html/js # страница отчёта: результат + предпросмотр сайта
└── icons/          # иконки 16/32/48/128
```

## Приватность

Расширение не собирает и не передаёт никаких данных, кроме домена/IP, который вы сами просите проверить. История проверок хранится локально в `chrome.storage.local`.
